# Job Listing App

A responsive job listing application built with React and Tailwind CSS.

## Features
- Responsive design
- Dynamic job listings
- Reusable React components
- JSON data mapping

## Tech Stack
- React
- Tailwind CSS
- JavaScript
- Vite
